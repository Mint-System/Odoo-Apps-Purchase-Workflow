- Open Setting > Technical > Email > Email Templates
- Open a purchase related template "Purchase: Request For Quotation"
- In the email configuration tab remove the entry in the To (Partners) field
- Open another template "Purchase: Vendor Reminder"
- In the email configuration tab, enter the value ${object.partner_order_id.id} into the To (Partners) field.
- Open the contact for Azure Interior
- Create a new address "Order Address", set the contact email
- Open Purchase > Order > Purchase Orders and create a new order
- Choose Azure Interior as the vendor, the Order Address will be filled with the newly created address
- Press the "Send by Email" button, note that the recipient's email address comes form the Order Address
